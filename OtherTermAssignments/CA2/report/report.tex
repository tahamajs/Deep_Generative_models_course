\begin{abstract}
This report provides a complete and implementation-grounded treatment of CA2 in Deep Generative Models, covering both Masked Autoregressive Flow (MAF) and CycleGAN. For normalizing flows, we derive change-of-variables identities, Jacobian determinants for coupling-style transformations, and discuss autoregressive masking with MADE. We then present the implemented MAF pipeline, training objective, generation-time versus training-time behavior, anomaly detection methodology based on negative log-likelihood, and metric design with AUROC. For CycleGAN, we answer all theoretical prompts regarding unpaired translation, cycle consistency, objective formulation, identity loss, architectural choices, PatchGAN motivation, replay buffer dynamics, and geometric limitations. The practical section documents complete CLI workflows, artifact generation, and report integration. Current included results are reproducible quick-mode outputs generated from the project code path, while full-data procedures are specified to obtain final benchmark-grade quantitative claims.
\end{abstract}

\section{Question 1: Normalizing Flows}

\subsection{Part 1 -- Theory}

\subsubsection{Change of Variables: General Derivation}
Let $x\in\mathbb{R}^D$, $z=f(x)$, where $f$ is bijective and differentiable. Densities satisfy
\begin{equation}
 p_X(x)=p_Z(f(x))\left|\det\frac{\partial f(x)}{\partial x}\right|.
\label{eq:cov_fwd}
\end{equation}
Equivalently, using $x=f^{-1}(z)$:
\begin{equation}
 p_X(x)=p_Z(z)\left|\det\frac{\partial f^{-1}(z)}{\partial z}\right|,\quad z=f(x).
\label{eq:cov_inv}
\end{equation}
For a sequence of flow blocks $f=f_K\circ\dots\circ f_1$, log-likelihood becomes
\begin{equation}
\log p_X(x)=\log p_Z(z_K)+\sum_{k=1}^{K}\log\left|\det\frac{\partial f_k}{\partial z_{k-1}}\right|.
\label{eq:chain_flow}
\end{equation}

\subsubsection{Closed-Form Example 1}
If $Z\sim\mathcal{U}(0,1)$ and $X=2Z+1$, then
\begin{equation}
 Z=\frac{X-1}{2},\quad \left|\frac{dZ}{dX}\right|=\frac{1}{2},\quad x\in[1,3].
\end{equation}
Hence
\begin{equation}
 p_X(x)=\begin{cases}
\frac{1}{2}, & 1\le x\le 3, \\
0, & \text{otherwise}.
\end{cases}
\end{equation}

\subsubsection{Closed-Form Example 2}
If $Z\sim\mathcal{U}(0,2)$ and $X=e^Z$, then
\begin{equation}
 Z=\ln X,\quad \left|\frac{dZ}{dX}\right|=\frac{1}{X},\quad x\in[1,e^2].
\end{equation}
Thus
\begin{equation}
 p_X(x)=\begin{cases}
\frac{1}{2x}, & 1\le x\le e^2,\\
0, & \text{otherwise}.
\end{cases}
\end{equation}

\subsubsection{Jacobian Determinants for Two Transform Families}

\paragraph{(a) Additive coupling}
For
\begin{equation}
 z_1=x_1,\qquad z_2=x_2+m(x_1),
\end{equation}
Jacobian is triangular:
\begin{equation}
J=
\begin{bmatrix}
1 & 0 \\
\frac{\partial m(x_1)}{\partial x_1} & 1
\end{bmatrix},
\qquad \det J=1.
\end{equation}
This is volume-preserving.

\paragraph{(b) Affine coupling}
For
\begin{equation}
 z_1=x_1,\qquad z_2=s(x_1)\odot x_2+t(x_1),
\end{equation}
Jacobian remains triangular with diagonal containing scale terms:
\begin{equation}
 \det J=\prod_i s_i(x_1),\qquad
 \log|\det J|=\sum_i \log|s_i(x_1)|.
\end{equation}

\subsection{Part 2 -- MAF Implementation}

\subsubsection{Autoregressive Factorization and MADE}
Autoregressive models use
\begin{equation}
 p(x)=\prod_{d=1}^{D}p(x_d\mid x_{<d}).
\end{equation}
In MADE, binary masks on dense layers enforce this dependency structure by design: output $d$ cannot depend on input dimensions $\ge d$.

\subsubsection{MAF Block Used in This Project}
Each block predicts shift and scale using a masked network:
\begin{equation}
[s(x),t(x)] = \text{MADE}(x).
\end{equation}
A stable positive scale is formed as
\begin{equation}
\sigma(x)=\text{sigmoid}(s(x)+2).
\end{equation}
Forward pass (used in likelihood computation):
\begin{equation}
z=\frac{x-t(x)}{\sigma(x)+\epsilon},
\quad
\log|\det J|=-\sum_i\log(\sigma_i(x)+\epsilon).
\end{equation}

Inverse pass (used in generation) is sequential:
\begin{equation}
x_i=\sigma_i(x_{<i})z_i+t_i(x_{<i}).
\end{equation}

\subsubsection{Training Objective}
With standard normal base distribution and $K$ flow blocks,
\begin{equation}
\mathcal{L}_{NLL}(\theta)
=-\frac{1}{N}\sum_{n=1}^{N}
\left[\log p_Z(z_n^{(K)})+
\sum_{k=1}^{K}\log\left|\det J_k\right|\right].
\end{equation}
Optimization uses Adam with configurable checkpointing, resume, and optional scheduler.

\paragraph{Interpretation}
Training/evaluation in MAF is relatively efficient because forward density evaluation is parallel per minibatch. Sampling is slow because inverse autoregressive generation is sequential over dimensions.

\paragraph{MAF vs IAF}
\begin{itemize}
\item \textbf{MAF:} fast density estimation, slow sampling.
\item \textbf{IAF:} fast sampling, slower exact likelihood use.
\end{itemize}
Therefore MAF is natural for anomaly scoring pipelines, while IAF is preferred when generation speed is primary.

\subsection{Part 3 -- Anomaly Detection}

\subsubsection{Why Accuracy is Not a Good Primary Metric}
In anomaly detection, class imbalance is typical (normal samples dominate). Accuracy can be high even for trivial detectors predicting only normal, so it does not reflect ranking quality.

\subsubsection{Recommended Metrics}
\begin{itemize}
\item \textbf{AUROC:} threshold-independent ranking quality.
\item \textbf{AUPRC:} useful under stronger imbalance.
\item \textbf{TPR/FPR at operating points:} deployment-oriented calibration.
\end{itemize}

\subsubsection{Anomaly Score Definition}
Using a trained flow model,
\begin{equation}
 s(x)=-\log p_\theta(x).
\end{equation}
Higher NLL indicates lower normal-data compatibility and higher anomaly likelihood.

\subsubsection{How Normal-Only Flow Training Enables Detection}
Training is performed only on normal images. The model learns high-density regions around normal manifold. At inference, anomalous samples tend to map to lower likelihood regions, yielding higher scores.

\subsubsection{VAE-Style Reconstruction Scoring vs Flow Models}
For VAEs, reconstruction error is commonly used as anomaly score due to approximate likelihood and bottleneck structure. For exact invertible flows, pure reconstruction error is less informative because inversion can remain faithful for many inputs. Thus likelihood-based scoring is primary; reconstruction-style terms can be auxiliary but are usually weaker than NLL for flow-based anomaly detection.

\section{Question 2: CycleGAN}

\subsection{Part 1 -- Theory}

\subsubsection{(1) Paired-data challenge in supervised translation}
Paired methods require aligned $(x,y)$ examples, which are expensive or impossible in many domains (season/style transfer, cross-modality medical imaging, wildlife domains, etc.).

\subsubsection{(2) Core CycleGAN idea and mathematical form}
CycleGAN learns two mappings:
\begin{equation}
G:X\to Y,\qquad F:Y\to X,
\end{equation}
using unpaired samples while enforcing cycle constraints:
\begin{equation}
F(G(x))\approx x,\qquad G(F(y))\approx y.
\end{equation}

\subsubsection{(3) Why cycle consistency is vital}
Without cycle consistency, adversarial objectives alone allow mappings that produce plausible target-style outputs but discard source content. Cycle loss regularizes mappings toward content-preserving transformations.

\subsubsection{(4) Full objective and role of $\lambda$}
Adversarial terms:
\begin{align}
\mathcal{L}_{GAN}(G,D_Y)
&=\mathbb{E}_{y}[\log D_Y(y)] \nonumber\\
&\quad+\mathbb{E}_{x}[\log(1-D_Y(G(x)))],\\
\mathcal{L}_{GAN}(F,D_X)
&=\mathbb{E}_{x}[\log D_X(x)] \nonumber\\
&\quad+\mathbb{E}_{y}[\log(1-D_X(F(y)))].
\end{align}
Cycle term:
\begin{equation}
\mathcal{L}_{cyc}(G,F)
=\mathbb{E}_{x}[\|F(G(x))-x\|_1]
+\mathbb{E}_{y}[\|G(F(y))-y\|_1].
\end{equation}
Identity term:
\begin{equation}
\mathcal{L}_{id}(G,F)
=\mathbb{E}_{y}[\|G(y)-y\|_1]
+\mathbb{E}_{x}[\|F(x)-x\|_1].
\end{equation}
Full objective:
\begin{equation}
\mathcal{L}=\mathcal{L}_{GAN}(G,D_Y)
+\mathcal{L}_{GAN}(F,D_X)
+\lambda_{cyc}\mathcal{L}_{cyc}
+\lambda_{id}\mathcal{L}_{id}.
\end{equation}
If $\lambda_{cyc}$ is too large, model behavior approaches identity mapping and translation strength degrades.

\subsubsection{(5) Identity loss and prevented artifacts}
Identity loss discourages unnecessary color/illumination shifts when the image is already in target domain, e.g., preventing unrealistic tint changes when style transformation should mostly alter texture.

\subsubsection{(6) Why two generators instead of one}
$X\to Y$ and $Y\to X$ are generally asymmetric tasks. Separate generators provide task-specific capacity and reduce optimization conflict.

\subsubsection{(7) Generator architecture vs pix2pix}
CycleGAN commonly uses ResNet-based generators (no heavy skip structure), unlike U-Net in pix2pix. Since data is unpaired, strict pixel alignment is unavailable; residual blocks emphasize style transformation with structural retention via cycle loss.

\subsubsection{(8) PatchGAN discriminator rationale}
PatchGAN makes local real/fake decisions on patches instead of the whole image. It improves texture realism and reduces parameter count while remaining fully convolutional.

\subsubsection{(9) Replay buffer motivation}
Using a history of generated images in discriminator updates reduces oscillation and prevents short-term forgetting of previously generated modes.

\subsubsection{(10) Geometric transformation limitation}
Large geometric changes are hard because cycle consistency penalizes irreversible shape transformations. CycleGAN is naturally biased toward texture/style changes with moderate geometric variation.

\subsection{Question 1 Direct Answers}
\subsubsection{Part 1 -- Theory}
\paragraph{1) Change of variables expressions}
Provided in Eqs. (1)--(4) with two closed-form examples (affine-transformed uniform and exponential transform of uniform).

\paragraph{2) Jacobian determinants}
Additive coupling determinant is 1 (volume-preserving). Affine coupling determinant is product of scaling outputs; log-determinant is sum of their logs.

\subsubsection{Part 2 -- Implementation}
\paragraph{1) MAF implementation details}
Implemented using masked linear layers in MADE to preserve autoregressive dependency. Each block predicts shift and scale, composed across multiple blocks.

\paragraph{2) Training and generation analysis}
Quick metrics show generation is much slower than training due to sequential inverse autoregressive sampling. This is expected behavior for MAF.

\paragraph{3) Why generation is slow}
Sampling requires dimension-wise inversion where each next dimension depends on previously sampled outputs.

\paragraph{4) Why IAF is faster for sampling}
IAF re-parameterizes direction of autoregression to make sampling parallel, trading off likelihood evaluation convenience.

\subsubsection{Part 3 -- Anomaly Detection}
\paragraph{1) Why not accuracy}
Accuracy is unstable under strong normal/anomaly imbalance and can hide poor anomaly recall.

\paragraph{2) Used metrics}
AUROC is primary; AUPRC and operating-point metrics are recommended for deployment.

\paragraph{3) Anomaly score concept}
Negative log-likelihood serves as anomaly score: higher score means lower compatibility with learned normal-data density.

\paragraph{4) Flow-based anomaly detection}
Train on normal data only, compute test NLLs, and evaluate separability via ROC/AUROC.

\paragraph{5) VAE-style reconstruction score comparison}
Reconstruction error is central for VAE anomaly detection; for exact invertible flows it is usually less discriminative than likelihood-based scoring.

\section{Extended Appendix: Algorithms and Practical Notes}
\subsection{Algorithm A: MAF Training and Evaluation Workflow}
\begin{algorithmic}[1]
\STATE Set random seed, device, and data paths.
\STATE If full dataset exists, load capsule train set with transforms; otherwise use quick synthetic fallback.
\STATE Initialize MAF with configured number of blocks and hidden widths.
\FOR{epoch $=1$ to $E$}
  \FOR{mini-batch $x$}
    \STATE Compute $z,\log p_\theta(x)$ with forward flow.
    \STATE Compute $\mathcal{L}_{NLL}=-\log p_\theta(x)$.
    \STATE Backpropagate and update parameters (Adam).
  \ENDFOR
  \STATE Optionally save checkpoint.
\ENDFOR
\STATE Save final model and loss plot.
\STATE For anomaly detection, compute $s(x)=-\log p_\theta(x)$ on normal and anomaly sets.
\STATE Compute AUROC and save ROC/histogram figures.
\end{algorithmic}

\subsection{Algorithm B: CycleGAN Training with Replay Buffer}
\begin{algorithmic}[1]
\STATE Load domain $A$ and $B$ datasets (or quick synthetic fallback).
\STATE Initialize $G_{AB}, G_{BA}, D_A, D_B$ and optimizers.
\STATE Initialize replay buffers for fake-$A$ and fake-$B$.
\FOR{epoch $=1$ to $E$}
  \FOR{paired mini-batches $(a,b)$}
    \STATE Generate $\hat{b}=G_{AB}(a)$ and $\hat{a}=G_{BA}(b)$.
    \STATE Reconstruct $\tilde{a}=G_{BA}(\hat{b})$, $\tilde{b}=G_{AB}(\hat{a})$.
    \STATE Compute generator objective:
    \[
      \mathcal{L}_G=\mathcal{L}_{GAN}^{AB}+\mathcal{L}_{GAN}^{BA}+\lambda_{cyc}\mathcal{L}_{cyc}+\lambda_{id}\mathcal{L}_{id}.
    \]
    \STATE Update generators.
    \STATE Query replay buffers and update discriminators with mixed historical/current fakes.
  \ENDFOR
  \STATE Store history and save checkpoints.
\ENDFOR
\STATE Save final checkpoints and training curves.
\STATE Run test inference and save translated sample figures.
\end{algorithmic}

\paragraph{MAF failure modes}
\begin{itemize}
\item \textbf{Numerical instability in scales:} very small scale values can create large gradients.

\item \textbf{Texture artifacts:} checkerboard patterns from upsampling can appear.
\item \textbf{Identity drift:} over-stylization when identity term is under-weighted.
\item \textbf{Geometry failure:} large pose/shape changes remain poor due to cycle constraints.
\end{itemize}

\section{Computational Complexity and Resource Budget}
\subsection{MAF Complexity Perspective}
For input dimensionality $D$ and $K$ flow blocks:
\begin{itemize}
\item Forward density pass (training/eval) is parallel over dimensions within each layer and scales with network cost per block.
\item Inverse sampling is sequential in $D$, so practical generation latency increases significantly with image resolution.
\end{itemize}
At high level:
\begin{equation}
T_{\text{forward}} \propto K \cdot C_{\text{MADE}}(D),\qquad
T_{\text{sample}} \propto K \cdot D \cdot C_{\text{MADE-step}}.
\end{equation}
This theoretical asymmetry is consistent with measured quick metrics (fast one-epoch training, slower per-image generation).

\subsection{CycleGAN Complexity Perspective}
CycleGAN updates require:
\begin{enumerate}
\item two generator forward passes,
\item two cycle reconstruction passes,
\item identity passes,
\item discriminator passes for real and replay-buffered fake samples.
\end{enumerate}
Hence one training iteration is compute-heavy even in quick mode, especially on CPU. This matches the quick-mode wall time where CycleGAN training dominates total runtime.

\subsection{Metric Definitions for Reported Claims}
For binary anomaly decisions under threshold $\tau$ on score $s(x)$:
\begin{align}
\text{TPR}(\tau) &= \frac{\text{TP}}{\text{TP}+\text{FN}}, \\
\text{FPR}(\tau) &= \frac{\text{FP}}{\text{FP}+\text{TN}}, \\
\text{Precision}(\tau) &= \frac{\text{TP}}{\text{TP}+\text{FP}}, \\
\text{Recall}(\tau) &= \text{TPR}(\tau), \\
F_1(\tau) &= \frac{2\cdot \text{Precision}\cdot \text{Recall}}
{\text{Precision}+\text{Recall}}.
\end{align}
Primary metric remains AUROC for threshold-independent ranking. For practical deployment interpretation, one operating point should be selected and reported with confusion-matrix counts.

\subsection{Uncertainty Quantification}
To reduce single-run bias, final reporting should include confidence intervals for AUROC via bootstrap sampling over the test set. Let $\widehat{A}^{(b)}$ denote AUROC from bootstrap sample $b=1,\dots,B$; then:
\begin{equation}
\text{CI}_{95\%} = \left[
\text{quantile}_{0.025}\left(\widehat{A}^{(b)}\right),
\text{quantile}_{0.975}\left(\widehat{A}^{(b)}\right)
\right].
\end{equation}
Recommended practice is $B\ge 500$ with fixed random seed for reproducibility.

\section{Oral Defense and Grading Readiness Appendix}
\subsection{Likely Technical Questions and Concise Answers}
\paragraph{Q1: Why choose MAF for anomaly detection?}
Because MAF gives exact likelihood evaluation in the forward direction, enabling principled score definition with negative log-likelihood and standard ranking metrics such as AUROC.

\paragraph{Q2: Why is MAF sampling slower than evaluation?}
Generation requires autoregressive inversion dimension-by-dimension, while likelihood evaluation is parallelizable across dimensions for each layer.

\paragraph{Q3: Why not report only accuracy in anomaly detection?}
Class imbalance can make accuracy misleading. AUROC and AUPRC better represent ranking and rare-event behavior.

\paragraph{Q4: Why does CycleGAN need cycle consistency?}
Without cycle constraints, adversarial objectives can map many inputs to plausible but content-unrelated outputs, harming semantic preservation.

\paragraph{Q5: What does identity loss fix in practice?}
It suppresses unnecessary color and tone shifts when an image is already in target-domain style.

\paragraph{Q6: Why include replay buffer?}
It stabilizes discriminator learning by exposing historical fake samples, reducing short-term oscillations.

\subsection{Quick Mathematical Reminders}
The flow objective combines base density and Jacobian correction:
\begin{equation}
\log p_X(x)=\log p_Z(f(x))+\log\left|\det\frac{\partial f(x)}{\partial x}\right|.
\end{equation}
For block composition, Jacobian log-determinants add across blocks. For CycleGAN, the full objective combines adversarial, cycle, and identity terms with tunable weights to balance realism and content retention.

\subsection{Compute and Time Budgeting}
To avoid under-running final benchmarks, wall-time should be planned before execution:
\begin{equation}
T_{\text{total}} \approx E \cdot T_{\text{epoch}} + T_{\text{eval}} + T_{\text{export}}.
\end{equation}
For CPU-only environments, this estimate is critical because CycleGAN iteration cost can dominate the full pipeline. If budget is limited, prioritize fewer but well-documented checkpoints over incomplete long runs.

\section{Statistical Reporting Standards}
\subsection{Minimum Quantitative Fields}
The final report should include the following fields for each main claim:
\begin{enumerate}
\item dataset name and split definition,
\item model configuration (key hyperparameters),
\item point metric (AUROC/AUPRC or rubric average),
\item uncertainty estimate (confidence interval or multi-run range),
\item threshold policy for classification metrics.
\end{enumerate}

\subsection{Macro and Micro Aggregation Guidance}
For multi-defect anomaly settings:
\begin{itemize}
\item \textbf{Macro average:} equal weight per defect class.
\item \textbf{Micro average:} aggregate across all samples.
\end{itemize}
Macro averages better reflect cross-defect robustness; micro averages better reflect global operating behavior when class supports differ.

\subsection{Recommendation for Multi-Seed Stability}
If compute allows, run multiple seeds and report mean plus spread:
\begin{equation}
\mu = \frac{1}{S}\sum_{s=1}^{S} m_s,\qquad
\sigma = \sqrt{\frac{1}{S}\sum_{s=1}^{S}(m_s-\mu)^2}.
\end{equation}
Even a small seed set (e.g., $S=3$) improves confidence over single-run claims.

\section{Expanded Failure Analysis Playbook}
\subsection{MAF Diagnostic Signatures}
\begin{itemize}
\item \textbf{AUROC near 0.5 with strong histogram overlap:} poor anomaly separability, often due to insufficient training signal or mismatched data distribution.
\item \textbf{Exploding/unstable NLL:} learning rate too high or unstable scale outputs.
\item \textbf{Reasonable NLL but weak defect detection:} likelihood-semantic mismatch; evaluate per-defect and consider additional feature-level baselines.
\end{itemize}

\subsection{CycleGAN Diagnostic Signatures}
\begin{itemize}
\item \textbf{Texture realism without structure retention:} cycle term under-enforced.
\item \textbf{Strong identity preservation but weak translation:} over-weighted identity/cycle penalties.
\item \textbf{Oscillatory artifacts across checkpoints:} discriminator-generator imbalance and replay insufficiency.
\end{itemize}
