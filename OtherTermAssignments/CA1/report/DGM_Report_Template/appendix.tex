\begin{itemize}
  \item ساختار پوشه‌ها: `code/`، `code/data/`، `code/models/`، `code/utils/` و `figures/`.

  \item ابزارهای تصویرسازی و محاسبهٔ معیارها در `code/utils/visualization.py` و `code/utils/metrics.py` قرار دارند.
\end{itemize}

\section{کد نمونهٔ پیوست}
در ادامه یک قطعهٔ نمونه برای ساختار `Encoder/Decoder` آورده شده است (Python/PyTorch — نمایشی):
\begin{program}[H]
\begin{minted}[frame=none]{python}
class Encoder(nn.Module):
  def __init__(self, latent_dim):
    super().__init__()
    self.conv = nn.Sequential(...)
    self.fc_mu = nn.Linear(..., latent_dim)
    self.fc_logvar = nn.Linear(..., latent_dim)
  def forward(self, x):
    h = self.conv(x).view(x.size(0), -1)
    return self.fc_mu(h), self.fc_logvar(h)
\end{minted}
\caption{نمونهٔ ساختار Encoder}
\end{program}
