\section{پرسش‌های نظری}

\subsection*{سوال ۱: میدان برداری}
	extbf{الف) نقش میدان برداری:}
در Flow Matching، میدان برداری $v_\theta(x,t)$ «سرعت لحظه‌ای» حرکت جرم احتمال را تعیین می‌کند؛ یعنی اگر نمونه‌ی اولیه $x_0$ از توزیع ساده (مثلاً نویز گاوسی) در $t=0$ داشته باشیم، با حل معادله دیفرانسیل
$\frac{dx}{dt}=v_\theta(x,t)$
نمونه در طول زمان به سمت توزیع داده حرکت کرده و در $t=1$ به نمونه‌ای از توزیع هدف تبدیل می‌شود.

	extbf{ب) تفاوت/شباهت با Diffusion:}
Diffusion ذاتاً تصادفی است (زنجیره مارکوف یا SDE) اما Flow Matching یک مدل تعیین‌گر مبتنی بر ODE است. شباهت مهم این است که فرم‌های تعیین‌گر diffusion (مثل \lr{probability flow ODE} یا \lr{DDIM}) از نظر ایده به یادگیری یک مسیر ODE نزدیک می‌شوند.

\subsection*{سوال ۲: مسیرهای خطی}
	extbf{الف) چرا مسیر خطی؟ آیا همیشه بهینه است؟}
مسیر خطی $x_t=(1-t)x_0+tx_1$ ساده‌ترین مسیر بین دو نقطه است و سرعت هدف در این مسیر ثابت می‌شود: $v_{\text{target}}=x_1-x_0$؛ این سادگی یادگیری را آسان می‌کند. بهینگی «کلی» نیازمند کوپلینگ بهینه (\lr{Optimal Transport}) بین $x_0$ و $x_1$ است؛ در غیر این صورت مسیر خطی صرفاً یک انتخاب ساده و پایدار است.

	extbf{ب) اثر بر پایداری و هزینه:}
هدف رگرسیون ثابت و کراندار معمولاً پایداری آموزش را بهتر می‌کند و تابع هزینه به یک \lr{Least Squares} ساده تبدیل می‌شود.

\subsection*{سوال ۳: بازنویسی تابع هزینه (Score Matching)}
برای کرنل اغتشاش گاوسی
$q(x_t|x_0)=\mathcal{N}(x_t;x_0,\sigma_t^2 I)$
داریم:
\begin{equation}
\nabla_{x_t}\log q(x_t|x_0)=\frac{x_0-x_t}{\sigma_t^2}.
\end{equation}
بنابراین آموزش مدل امتیاز $s_\theta(x_t,t)$ با کمینه‌سازی خطای مربعی نسبت به این گرادیان (طبق نتیجه‌ی \lr{Vincent et al.}) به فرم
$\mathbb{E}[\|s_\theta(x_t,t)-(x_0-x_t)/\sigma_t^2\|_2^2]$
قابل بازنویسی است.

\section{جزئیات پیاده‌سازی Flow Matching}

\subsection{معماری Transformer-based Flow Matching}

\textbf{مدل Flow Matching برای سری‌های زمانی:}
\begin{minted}[fontsize=\footnotesize]{python}
class TimeSeriesFlowMatching(nn.Module):
    def __init__(self, input_dim=1, hidden_dim=128, num_layers=4, num_heads=8):
        super().__init__()
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        
        # Time embedding
        self.time_embed = nn.Sequential(
            SinusoidalEmbedding(hidden_dim),
            nn.Linear(hidden_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
        
        # Input projection
        self.input_proj = nn.Linear(input_dim, hidden_dim)
        
        # Transformer layers
        self.layers = nn.ModuleList([
            nn.TransformerEncoderLayer(
                d_model=hidden_dim,
                nhead=num_heads,
                dim_feedforward=4*hidden_dim,
                dropout=0.1,
                batch_first=True
            ) for _ in range(num_layers)
        ])
        
        # Output projection
        self.output_proj = nn.Linear(hidden_dim, input_dim)
        
        # Normalization
        self.norm = nn.LayerNorm(hidden_dim)
    
    def forward(self, x, t):
        """
        Args:
            x: [batch_size, seq_len, input_dim]
            t: [batch_size] time steps
        Returns:
            velocity: [batch_size, seq_len, input_dim]
        """
        batch_size, seq_len, _ = x.shape
        
        # Time embedding
        t_embed = self.time_embed(t.unsqueeze(-1))  # [batch_size, hidden_dim]
        t_embed = t_embed.unsqueeze(1).expand(-1, seq_len, -1)  # [batch_size, seq_len, hidden_dim]
        
        # Input projection
        h = self.input_proj(x)  # [batch_size, seq_len, hidden_dim]
        
        # Add time conditioning
        h = h + t_embed
        
        # Apply transformer layers
        for layer in self.layers:
            h = layer(h)
        
        # Output projection
        velocity = self.output_proj(self.norm(h))
        
        return velocity
\end{minted}

\textbf{Embedding زمانی سینوسی:}
\begin{minted}[fontsize=\footnotesize]{python}
class SinusoidalEmbedding(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim
    
    def forward(self, t):
        """
        Args:
            t: [batch_size] time values in [0, 1]
        Returns:
            embedding: [batch_size, dim]
        """
        device = t.device
        half_dim = self.dim // 2
        emb = math.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim, device=device) * -emb)
        emb = t.unsqueeze(-1) * emb.unsqueeze(0)
        emb = torch.cat([torch.sin(emb), torch.cos(emb)], dim=-1)
        
        if self.dim % 2 == 1:
            emb = torch.cat([emb, torch.zeros_like(emb[:, :1])], dim=-1)
        
        return emb
\end{minted}

\subsection{Conditional Flow Matching Training}

\textbf{کلاس Conditional Flow Matching:}
\begin{minted}[fontsize=\footnotesize]{python}
class ConditionalFlowMatching:
    def __init__(self, model, sigma=0.0):
        self.model = model
        self.sigma = sigma
    
    def sample_conditional_path(self, x0, x1, t):
        """
        Sample from conditional path p_t(x|x0,x1)
        """
        # Linear interpolation path
        path = (1 - t) * x0 + t * x1
        
        # Add noise for smoothing
        if self.sigma > 0:
            noise = torch.randn_like(path) * self.sigma
            path = path + noise
        
        return path
    
    def get_conditional_velocity(self, x0, x1, t):
        """
        Get target velocity for conditional flow matching
        """
        return x1 - x0
    
    def compute_loss(self, x0, x1, t):
        """
        Compute conditional flow matching loss
        Args:
            x0: [batch_size, seq_len, input_dim] source data
            x1: [batch_size, seq_len, input_dim] target data  
            t: [batch_size] time steps
        """
        # Sample from conditional path
        xt = self.sample_conditional_path(x0, x1, t)
        
        # Get target velocity
        target_velocity = self.get_conditional_velocity(x0, x1, t)
        
        # Predict velocity
        pred_velocity = self.model(xt, t)
        
        # Compute MSE loss
        loss = F.mse_loss(pred_velocity, target_velocity)
        
        return loss
\end{minted}

\textbf{کلاس Dataset برای سری‌های زمانی:}
\begin{minted}[fontsize=\footnotesize]{python}
class TimeSeriesDataset(Dataset):
    def __init__(self, data, seq_len=100, stride=10):
        """
        Args:
            data: [num_samples, time_steps, features]
            seq_len: length of sequences to extract
            stride: stride for sliding window
        """
        self.data = torch.tensor(data, dtype=torch.float32)
        self.seq_len = seq_len
        self.stride = stride
        
        # Extract sequences
        self.sequences = []
        for i in range(0, data.shape[1] - seq_len + 1, stride):
            self.sequences.append(data[:, i:i+seq_len])
        
        self.sequences = torch.stack(self.sequences)  # [num_sequences, num_samples, seq_len, features]
    
    def __len__(self):
        return len(self.sequences)
    
    def __getitem__(self, idx):
        seq = self.sequences[idx]  # [num_samples, seq_len, features]
        
        # Randomly select one sample from batch
        sample_idx = torch.randint(0, seq.shape[0], (1,)).item()
        x = seq[sample_idx]  # [seq_len, features]
        
        return x
\end{minted}

\textbf{حلقه آموزش:}
\begin{minted}[fontsize=\footnotesize]{python}
def train_flow_matching(model, dataset, num_epochs=100, batch_size=32, lr=1e-4):
    dataloader = DataLoader(dataset, batch_size=batch_size, shuffle=True)
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    
    cfm = ConditionalFlowMatching(model)
    
    for epoch in range(num_epochs):
        epoch_loss = 0
        
        for batch in dataloader:
            x1 = batch.to(device)  # Target data
            x0 = torch.randn_like(x1)  # Source noise
            
            # Sample time steps
            t = torch.rand(batch_size, device=device)
            
            # Compute loss
            loss = cfm.compute_loss(x0, x1, t)
            
            # Backprop
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            epoch_loss += loss.item()
        
        print(f"Epoch {epoch+1}/{num_epochs}, Loss: {epoch_loss/len(dataloader):.4f}")
    
    return model
\end{minted}

\subsection{نمونه‌گیری با ODE Solver}

\textbf{ODE Solver برای تولید:}
\begin{minted}[fontsize=\footnotesize]{python}
def sample_from_flow(model, x0, num_steps=100):
    """
    Generate samples using ODE solver
    Args:
        model: trained flow model
        x0: [batch_size, seq_len, input_dim] initial noise
        num_steps: number of integration steps
    Returns:
        generated samples
    """
    dt = 1.0 / num_steps
    xt = x0.clone()
    
    for i in range(num_steps):
        t = i * dt
        t_tensor = torch.full((x0.shape[0],), t, device=device)
        
        # Predict velocity
        vt = model(xt, t_tensor)
        
        # Euler step
        xt = xt + vt * dt
    
    return xt
\end{minted}

\subsection{تابع هزینه}
تابع هزینه‌ی استفاده‌شده مطابق رابطه‌ی زیر است که سرعت پیش‌بینی‌شده‌ی میدان برداری را به سرعت هدف
\lr{$v_{\text{target}} = x_1 - x_0$}
روی مسیر خطی \lr{$x_t = (1-t)x_0 + tx_1$} نزدیک می‌کند:
\begin{equation}
\mathcal{L} = \mathbb{E}_{x_0, x_1, t} \left[ \left\| v_\theta(x_t, t) - (x_1 - x_0) \right\|_2^2 \right].
\end{equation}

\noindent\textbf{کد اصلی تابع هزینه در پیاده‌سازی:}
\begin{minted}[fontsize=\footnotesize]{python}
t = torch.rand(batch_size, device=device)  # t ~ Uniform(0,1)
t_view = t.view(batch_size, 1, 1)
x_t = (1.0 - t_view) * x0 + t_view * x1
v_target = x1 - x0
v_pred = model(x_t, t)
loss = F.mse_loss(v_pred, v_target)
\end{minted}

\subsection{گام ۳: نمونه‌گیری با حل‌گرهای ODE (Euler/Heun)}
در نمونه‌گیری، ODE به صورت عددی حل می‌شود. افزایش تعداد گام‌ها هزینه محاسبات را بالا می‌برد اما معمولاً کیفیت را بهتر می‌کند.
\begin{minted}[fontsize=\footnotesize]{python}
def euler_step(x, t, dt):
	return x + dt * v_theta(x, t)

def heun_step(x, t, dt):
	k1 = v_theta(x, t)
	x_e = x + dt * k1
	k2 = v_theta(x_e, t + dt)
	return x + 0.5 * dt * (k1 + k2)
\end{minted}

در مجموع، نتایج بالا نشان می‌دهد که مدل Flow Matching توانسته است هم توزیع حاشیه‌ای بازده‌ها و هم بخشی از وابستگی زمانی آن‌ها را به‌خوبی بازتولید کند، هرچند بهبودهای بیشتر (مثلاً افزایش ظرفیت مدل یا استفاده از حل‌گرهای دقیق‌تر \lr{ODE}) می‌تواند نتایج را بهتر کند.
