# next_year — Claude Code Guidance

**Purpose**: Templates, draft materials, and future-course artifacts.  
**Parent Context**: Extends root `../CLAUDE.md`

## Rules
- Treat this directory as scaffolding; do not mix with current CA deliverables.
- Keep templates intact; copy before editing to avoid losing originals.
- Any new assignments or code sketches must include seeds/config in the first cell or module block.
- Reports for future assignments must follow IEEE format and live beside their code in the corresponding future folder.

## Allowed Actions
- Read templates and references.
- Create new draft Markdown/LaTeX in clearly named subfolders without overwriting existing templates.

## Disallowed Actions
- Moving current-year CA assets here.
- Committing large binaries (PDFs, fonts, images) without necessity.

## Safety
- If adding fonts or figures, ensure licensing permits storage; prefer linking to sources.
- Keep experimental code small and documented; promote to main CA folders only when stabilized.
