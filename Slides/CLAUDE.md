# Slides — Claude Code Guidance

**Purpose**: Lecture slides and reference decks (`DGM_Fall_2023_Slides/`, `Stanford_slides/`).  
**Parent Context**: Extends root `../CLAUDE.md`

## Rules

- Treat all slide decks (PDF/PPTX) as read-only. Do not edit or regenerate unless explicitly tasked.
- Do not commit new binaries here without approval; avoid bloating repo size.
- Cite slides if referenced in reports; do not copy verbatim without attribution.

## Allowed Actions

- Read and reference content for reports/notebooks.
- Add brief Markdown notes (new file) if absolutely needed; do not alter existing slide files.

## Disallowed Actions

- Modifying PDFs/PPTX directly.
- Deleting or relocating slide files without explicit confirmation.

## Safety

- If you must add a derivative, place it outside this folder (e.g., in a CA `report/` with proper citation).
- Keep this folder clean of generated artifacts or caches.
