\section{Theoretical Background}

\subsection{Variational Autoencoders (VAEs)}

Variational Autoencoders are a class of generative models that learn probabilistic representations of data by combining the compression capabilities of traditional autoencoders with probabilistic inference.

\paragraph{Motivation and Background:}
Traditional autoencoders learn deterministic mappings from input space to a bottleneck latent representation and back to the input space. While effective for compression and denoising, deterministic latent spaces have several limitations:
\begin{itemize}
    \item \textbf{Hole Problem}: Gaps in latent space may not correspond to valid data samples, making generation unreliable
    \item \textbf{Discontinuous Manifold}: Interpolation between latent vectors may produce unrealistic outputs
    \item \textbf{No Probabilistic Interpretation}: Cannot model uncertainty or sample from learned distribution
\end{itemize}

VAEs address these limitations by introducing probabilistic latent variables. Instead of mapping each input to a single latent vector, VAEs map inputs to probability distributions over latent space. This probabilistic formulation enables:
\begin{itemize}
    \item Meaningful sampling from the latent space
    \item Smooth interpolation between data points
    \item Uncertainty quantification in the latent representation
    \item Theoretical foundation connecting to variational inference and maximum likelihood estimation
\end{itemize}

\paragraph{Probabilistic Framework:}
The VAE models the joint distribution $p_\theta(\mathbf{x}, \mathbf{z}) = p_\theta(\mathbf{x}|\mathbf{z})p(\mathbf{z})$ where:
\begin{itemize}
    \item $p(\mathbf{z}) = \mathcal{N}(0, I)$: Prior distribution on latent variables (typically standard normal)
    \item $p_\theta(\mathbf{x}|\mathbf{z})$: Generative model (decoder) that maps latent vectors to data space
    \item $q_\phi(\mathbf{z}|\mathbf{x})$: Approximate posterior (encoder) that infers latent variables from data
\end{itemize}

The encoder $q_\phi(\mathbf{z}|\mathbf{x})$ is introduced because the true posterior $p(\mathbf{z}|\mathbf{x})$ is intractable to compute directly. The encoder approximates this posterior using a neural network that outputs the parameters (mean and variance) of a Gaussian distribution.

\subsection{Key Concepts}

\subsubsection{Probabilistic Latent Space}

Unlike deterministic autoencoders, VAEs learn a probabilistic latent space where each input $x$ is encoded into a distribution $q_\phi(z|x)$ rather than a fixed point. This enables meaningful generation and interpolation.

\subsubsection{Evidence Lower Bound (ELBO)}

The training objective maximizes the Evidence Lower Bound (ELBO), which is a lower bound on the log-likelihood of the data.

\paragraph{Derivation of ELBO:}
We wish to maximize the log-likelihood of the data:
\begin{equation}
\log p_\theta(\mathbf{x}) = \log \int p_\theta(\mathbf{x}|\mathbf{z})p(\mathbf{z}) d\mathbf{z}
\end{equation}

However, this integral is intractable. Using Jensen's inequality and introducing the approximate posterior $q_\phi(\mathbf{z}|\mathbf{x})$:

\begin{align}
\log p_\theta(\mathbf{x}) &= \log \int p_\theta(\mathbf{x}|\mathbf{z})p(\mathbf{z}) d\mathbf{z} \\
&= \log \int q_\phi(\mathbf{z}|\mathbf{x}) \frac{p_\theta(\mathbf{x}|\mathbf{z})p(\mathbf{z})}{q_\phi(\mathbf{z}|\mathbf{x})} d\mathbf{z} \\
&\geq \int q_\phi(\mathbf{z}|\mathbf{x}) \log \frac{p_\theta(\mathbf{x}|\mathbf{z})p(\mathbf{z})}{q_\phi(\mathbf{z}|\mathbf{x})} d\mathbf{z} \quad \text{(Jensen's inequality)} \\
&= \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}[\log p_\theta(\mathbf{x}|\mathbf{z})] - \text{KL}(q_\phi(\mathbf{z}|\mathbf{x}) || p(\mathbf{z}))
\end{align}

The training objective is:

\begin{equation}
\mathcal{L}(\theta, \phi; \mathbf{x}) = \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})} [\log p_\theta(\mathbf{x}|\mathbf{z})] - \text{KL}(q_\phi(\mathbf{z}|\mathbf{x}) || p(\mathbf{z}))
\end{equation}

where:
\begin{itemize}
    \item $p_\theta(\mathbf{x}|\mathbf{z})$: Decoder (generative model) that reconstructs data from latent variables
    \item $q_\phi(\mathbf{z}|\mathbf{x})$: Encoder (recognition model) that infers latent variables from data
    \item $p(\mathbf{z})$: Prior distribution (typically $\mathcal{N}(0, I)$)
\end{itemize}

\paragraph{Interpretation of ELBO Components:}

The ELBO consists of two competing terms:

\begin{enumerate}
    \item \textbf{Reconstruction Term} $\mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})} [\log p_\theta(\mathbf{x}|\mathbf{z})]$:
    \begin{itemize}
        \item Encourages the decoder to accurately reconstruct input data
        \item Maximized when $p_\theta(\mathbf{x}|\mathbf{z})$ assigns high probability to the original input
        \item Can be approximated by sampling $\mathbf{z} \sim q_\phi(\mathbf{z}|\mathbf{x})$ and computing $\log p_\theta(\mathbf{x}|\mathbf{z})$
        \item In practice, often uses a single sample (or multiple samples for variance reduction)
    \end{itemize}
    
    \item \textbf{Regularization Term} $-\text{KL}(q_\phi(\mathbf{z}|\mathbf{x}) || p(\mathbf{z}))$:
    \begin{itemize}
        \item Penalizes deviation of the approximate posterior from the prior
        \item Ensures the latent space has structure compatible with the prior distribution
        \item Prevents the encoder from collapsing to a point distribution (posterior collapse)
        \item Enables meaningful sampling from the prior for generation
    \end{itemize}
\end{enumerate}

\paragraph{Trade-off:}
The two terms create a fundamental trade-off:
\begin{itemize}
    \item High reconstruction weight $\rightarrow$ Better image quality, but latent space may not be smooth or generative
    \item High KL weight $\rightarrow$ Smoother latent space, but reconstructions may be blurrier
    \item Optimal balance is task-dependent and learned during training
\end{itemize}

\subsubsection{Reparameterization Trick}

The reparameterization trick is essential for enabling gradient-based optimization when the objective involves stochastic latent variables.

\paragraph{Problem with Direct Sampling:}
If we directly sample from the encoder distribution:
\begin{equation}
\mathbf{z} \sim q_\phi(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\boldsymbol{\mu}_\phi(\mathbf{x}), \boldsymbol{\sigma}_\phi^2(\mathbf{x}))
\end{equation}

We cannot backpropagate gradients through the sampling operation because it involves random noise. The gradient $\nabla_\phi \mathbb{E}_{\mathbf{z} \sim q_\phi(\mathbf{z}|\mathbf{x})}[\log p_\theta(\mathbf{x}|\mathbf{z})]$ is undefined.

\paragraph{Solution: Reparameterization:}
We rewrite the sampling operation to separate the stochastic component from the learnable parameters:

\begin{equation}
\mathbf{z} = \boldsymbol{\mu}_\phi(\mathbf{x}) + \boldsymbol{\sigma}_\phi(\mathbf{x}) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)
\end{equation}

where $\boldsymbol{\sigma}_\phi(\mathbf{x}) = \exp(0.5 \times \logvar_\phi(\mathbf{x}))$ to ensure positivity.

\paragraph{Why This Works:}
\begin{itemize}
    \item \textbf{Deterministic Path}: $\boldsymbol{\mu}_\phi(\mathbf{x})$ and $\boldsymbol{\sigma}_\phi(\mathbf{x})$ are deterministic functions of $\mathbf{x}$ and $\phi$, so gradients can flow through them
    \item \textbf{Stochastic Path}: $\epsilon$ is independent of $\phi$ and sampled from a fixed distribution, so it doesn't block gradients
    \item \textbf{Gradient Estimator}: The gradient can now be estimated as:
    \begin{equation}
    \nabla_\phi \mathbb{E}_{\epsilon \sim \mathcal{N}(0,I)}[\log p_\theta(\mathbf{x}|\boldsymbol{\mu}_\phi(\mathbf{x}) + \boldsymbol{\sigma}_\phi(\mathbf{x}) \odot \epsilon)] = \mathbb{E}_{\epsilon \sim \mathcal{N}(0,I)}[\nabla_\phi \log p_\theta(\mathbf{x}|\mathbf{z})]
    \end{equation}
\end{itemize}

\paragraph{Implementation Considerations:}
\begin{itemize}
    \item \textbf{Numerical Stability}: We use $\logvar$ instead of $\sigma^2$ to avoid numerical issues and ensure positivity
    \item \textbf{Clamping}: In practice, we clamp $\logvar$ to reasonable bounds (e.g., [-10, 10]) to prevent extreme values
    \item \textbf{Sampling}: For training, typically one sample per input is sufficient; for inference, can use multiple samples for better estimates
\end{itemize}

\subsubsection{Loss Function Components}

The total loss consists of two components:

\begin{equation}
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{recon}} + \mathcal{L}_{\text{KL}}
\end{equation}

\paragraph{Reconstruction Loss:}
\begin{equation}
\mathcal{L}_{\text{recon}} = \frac{1}{N} \sum_{i=1}^{N} ||\mathbf{x}_i - \hat{\mathbf{x}}_i||^2
\end{equation}

\paragraph{KL Divergence Loss:}
The KL divergence term has a closed-form expression when both distributions are Gaussian. For $q_\phi(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}^2))$ and $p(\mathbf{z}) = \mathcal{N}(0, I)$:

\begin{equation}
\text{KL}(q_\phi(\mathbf{z}|\mathbf{x}) || p(\mathbf{z})) = \sum_{j=1}^{d} \text{KL}(\mathcal{N}(\mu_j, \sigma_j^2) || \mathcal{N}(0, 1))
\end{equation}

For univariate Gaussians:
\begin{align}
\text{KL}(\mathcal{N}(\mu, \sigma^2) || \mathcal{N}(0, 1)) &= \frac{1}{2}\left(\sigma^2 + \mu^2 - 1 - \log(\sigma^2)\right) \\
&= \frac{1}{2}\left(\sigma^2 + \mu^2 - 1 - 2\log(\sigma)\right)
\end{align}

In terms of $\logvar = \log(\sigma^2)$:
\begin{equation}
\mathcal{L}_{\text{KL}} = -\frac{1}{2} \sum_{j=1}^{d} (1 + \logvar_j - \mu_j^2 - \exp(\logvar_j))
\end{equation}

\paragraph{Interpretation of KL Divergence:}
\begin{itemize}
    \item The KL term encourages the posterior $q_\phi(\mathbf{z}|\mathbf{x})$ to match the prior $p(\mathbf{z}) = \mathcal{N}(0, I)$
    \item This ensures that:
    \begin{enumerate}
        \item Latent space is centered around zero (via the $\mu_j^2$ term)
        \item Latent dimensions have unit variance on average (via the $-\exp(\logvar_j)$ term)
        \item No dimensions collapse to zero variance (via the $\logvar_j$ term)
    \end{enumerate}
    \item The regularization prevents the encoder from learning arbitrary distributions and encourages a smooth, well-behaved latent space
    \item This is crucial for generation: if we sample $\mathbf{z} \sim \mathcal{N}(0, I)$, we want the decoder to produce realistic images
\end{itemize}

\paragraph{Posterior Collapse:}
If KL divergence becomes too small during training, the posterior collapses:
\begin{itemize}
    \item Encoder outputs $\mu = 0$ and $\sigma^2 = 1$ regardless of input
    \item All inputs map to the same latent distribution
    \item Model ignores input information (mode collapse)
    \item Can be prevented by adjusting the weight of KL term or using techniques like KL annealing
\end{itemize}

    \item \textbf{Convergence Speed}: Normalized data typically allows for faster and more stable convergence.
\end{itemize}

\subsection{Exercise 2: VAE Model Implementation}

\subsubsection{Objective}
Implement the complete VAE architecture with encoder, reparameterization trick, and decoder.

\subsubsection{Key Implementation Details}

\paragraph{Reparameterization Trick:}
The reparameterization trick is implemented as follows:
\begin{lstlisting}[language=Python]
def reparameterize(self, mean, logvar):
    logvar = torch.clamp(logvar, min=-10, max=10)
    std_dev = torch.exp(0.5 * logvar)
    epsilon = torch.randn_like(std_dev)
    return mean + epsilon * std_dev
\end{lstlisting}

\textbf{Detailed Analysis:}

\paragraph{Numerical Stability with Clamping:}
\begin{itemize}
    \item \texttt{torch.clamp(logvar, min=-10, max=10)}: 
    \begin{itemize}
        \item Prevents extreme values that could cause numerical underflow or overflow
        \item If $\logvar < -10$: $\sigma = \exp(0.5 \times (-10)) \approx 0.0067$ (very small variance)
        \item If $\logvar > 10$: $\sigma = \exp(0.5 \times 10) \approx 148.4$ (very large variance)
        \item This range is sufficient for most practical cases while preventing numerical issues
        \item Without clamping, extreme $\logvar$ values could cause $\exp()$ to overflow or produce near-zero values causing division by zero
    \end{itemize}
\end{itemize}

\paragraph{Log-Variance Parameterization:}
\begin{itemize}
    \item \texttt{std\_dev = torch.exp(0.5 * logvar)}: 
    \begin{itemize}
        \item Using $\logvar$ instead of $\sigma^2$ ensures positivity without constraints
        \item Avoids need for softplus or other positive activations
        \item Enables unconstrained optimization: the network can output any real value
        \item The factor of 0.5 comes from: $\sigma = \sqrt{\sigma^2} = \exp(\log(\sqrt{\sigma^2})) = \exp(0.5 \log(\sigma^2)) = \exp(0.5 \times \logvar)$
    \end{itemize}
\end{itemize}

\paragraph{Sampling Procedure:}
\begin{itemize}
    \item \texttt{epsilon $\sim$ $\mathcal{N}(0,I)$}: 
    \begin{itemize}
        \item Samples random noise from standard normal distribution
        \item Independent of model parameters, enabling gradient flow
        \item Same dimensionality as mean and logvar vectors (32 dimensions in our case)
        \item During training, different $\epsilon$ values are sampled each forward pass, providing stochasticity
    \end{itemize}
\end{itemize}

\paragraph{Gradient Flow:}
\begin{itemize}
    \item The reparameterization creates a deterministic path: $\mathbf{z} = \boldsymbol{\mu} + \boldsymbol{\sigma} \odot \epsilon$
    \item Gradients can flow through $\boldsymbol{\mu}$ and $\boldsymbol{\sigma}$ (deterministic functions of encoder parameters)
    \item The stochastic component $\epsilon$ doesn't block gradients because it's independent of parameters
    \item This enables end-to-end training of both encoder and decoder using standard backpropagation
\end{itemize}

\paragraph{Forward Pass:}
The forward method combines encoding, reparameterization, and decoding:

\begin{enumerate}
    \item \textbf{Encoding Phase}:
    \begin{itemize}
        \item Input image $\mathbf{x} \in \mathbb{R}^{3 \times 128 \times 128}$ passes through convolutional encoder
        \item Convolutional layers extract hierarchical features (edges → shapes → high-level features)
        \item Features are flattened and passed through fully connected layers
        \item Encoder outputs:
        \begin{itemize}
            \item $\boldsymbol{\mu}_\phi(\mathbf{x}) \in \mathbb{R}^{32}$: Mean of latent distribution
            \item $\logvar_\phi(\mathbf{x}) \in \mathbb{R}^{32}$: Log-variance of latent distribution
        \end{itemize}
    \end{itemize}
    
    \item \textbf{Reparameterization Phase}:
    \begin{itemize}
        \item Sample $\epsilon \sim \mathcal{N}(0, I)$ from standard normal distribution
        \item Compute $\boldsymbol{\sigma} = \exp(0.5 \times \logvar)$
        \item Generate latent vector: $\mathbf{z} = \boldsymbol{\mu} + \boldsymbol{\sigma} \odot \epsilon$
        \item This $\mathbf{z}$ represents a point in the latent space sampled from $q_\phi(\mathbf{z}|\mathbf{x})$
    \end{itemize}
    
    \item \textbf{Decoding Phase}:
    \begin{itemize}
        \item Latent vector $\mathbf{z}$ is expanded through fully connected layers
        \item Reshaped to 256×8×8 for transposed convolutional processing
        \item Transposed convolutions upscale feature maps: 8×8 → 16×16 → 32×32 → 64×64 → 128×128
        \item Final Tanh activation ensures output in $[-1, 1]$ range
        \item Output: $\hat{\mathbf{x}} \in \mathbb{R}^{3 \times 128 \times 128}$ (reconstructed image)
    \end{itemize}
    
    \item \textbf{Return Values}:
    \begin{itemize}
        \item \texttt{reconstructed\_output}: $\hat{\mathbf{x}}$ for computing reconstruction loss
        \item \texttt{mean}: $\boldsymbol{\mu}$ for computing KL divergence
        \item \texttt{logvar}: $\logvar$ for computing KL divergence and future reparameterization
    \end{itemize}
\end{enumerate}

\paragraph{Architecture Design Rationale:}
\begin{itemize}
    \item \textbf{Convolutional Encoder}: Captures spatial patterns and hierarchical features efficiently
    \item \textbf{Bottleneck Dimension (32)}: Forces compression while maintaining essential information
    \item \textbf{Symmetric Decoder}: Mirrors encoder structure for intuitive upsampling
    \item \textbf{BatchNorm and Dropout}: Regularization prevents overfitting and improves generalization
    \item \textbf{LeakyReLU}: Prevents dying ReLU problem, allows small negative gradients
\end{itemize}

\subsection{Exercise 3: Loss Function Implementation}

\subsubsection{Objective}
Implement the VAE loss function combining reconstruction and KL divergence terms.

\subsubsection{Implementation}
\begin{lstlisting}[language=Python]
def vae_loss_function(reconstructed_x, original_x, latent_mean, latent_logvar):
    reconstruction_loss = nn.functional.mse_loss(
        reconstructed_x, original_x, reduction='sum'
    )
    kl_divergence_loss = -0.5 * torch.sum(
        1 + latent_logvar - latent_mean.pow(2) - latent_logvar.exp()
    )
    total_loss = reconstruction_loss + kl_divergence_loss
    return total_loss, reconstruction_loss, kl_divergence_loss
\end{lstlisting}

\subsubsection{Analysis}

\paragraph{Reconstruction Loss:}

The reconstruction loss measures the difference between original and reconstructed images.

\begin{itemize}
    \item \textbf{MSE with 'sum' reduction}: 
    \begin{itemize}
        \item Computes: $\sum_{i,j,k} (x_{i,j,k} - \hat{x}_{i,j,k})^2$ over all pixels and channels
        \item 'sum' rather than 'mean' gives larger loss values but keeps gradients proportional
        \item The magnitude will be averaged later when dividing by dataset size
    \end{itemize}
    
    \item \textbf{Why MSE?}:
    \begin{itemize}
        \item Assumes Gaussian noise in reconstruction: $p_\theta(\mathbf{x}|\mathbf{z}) = \mathcal{N}(\mathbf{x}; \hat{\mathbf{x}}, \sigma^2 I)$
        \item For Gaussian likelihood: $\log p_\theta(\mathbf{x}|\mathbf{z}) \propto -||\mathbf{x} - \hat{\mathbf{x}}||^2$
        \item MSE directly corresponds to maximizing log-likelihood under Gaussian assumption
        \item Works well for natural images, penalizing all pixel differences equally
    \end{itemize}
    
    \item \textbf{Alternative Loss Functions}:
    \begin{itemize}
        \item L1 loss ($|\mathbf{x} - \hat{\mathbf{x}}|$): More robust to outliers, encourages sparsity
        \item Perceptual loss: Uses features from pre-trained networks (VGG), better captures semantic similarity
        \item Adversarial loss: Combined with discriminator (VAE-GAN) for sharper images
    \end{itemize}
    
    \item \textbf{Loss Interpretation}:
    \begin{itemize}
        \item Lower loss $\rightarrow$ Better reconstruction quality
        \item Loss decreases from $\sim$6489 (initial) to $\sim$2807 (converged)
        \item This represents per-sample averaged loss across all pixels
    \end{itemize}
\end{itemize}

\paragraph{KL Divergence Loss:}

The KL divergence term implements the closed-form expression for Gaussian distributions.

\begin{itemize}
    \item \textbf{Mathematical Formulation}:
    \begin{itemize}
        \item For diagonal Gaussian: $q_\phi(\mathbf{z}|\mathbf{x}) = \prod_{j=1}^{d} \mathcal{N}(z_j; \mu_j, \sigma_j^2)$
        \item KL divergence decomposes: $\text{KL}(q||p) = \sum_{j=1}^{d} \text{KL}(q_j||p_j)$
        \item Each term: $\text{KL}(\mathcal{N}(\mu_j, \sigma_j^2) || \mathcal{N}(0, 1)) = \frac{1}{2}(\sigma_j^2 + \mu_j^2 - 1 - \log(\sigma_j^2))$
        \item Implementation uses: $-\frac{1}{2}\sum(1 + \logvar - \mu^2 - \exp(\logvar))$
    \end{itemize}
    
    \item \textbf{Regularization Mechanism}:
    \begin{itemize}
        \item $\mu_j^2$ term: Encourages means to be close to zero
        \item $\sigma_j^2$ term: Encourages variances to be close to 1
        \item $-\log(\sigma_j^2)$ term: Prevents variance collapse (penalizes very small variances)
        \item Together: Shapes latent distribution to match $\mathcal{N}(0, I)$
    \end{itemize}
    
    \item \textbf{Training Dynamics}:
    \begin{itemize}
        \item Initially: KL loss may be high as encoder learns to match prior
        \item During training: Decreases as posterior converges toward prior
        \item At convergence: Should stabilize, indicating balanced regularization
        \item Too low: Risk of posterior collapse (encoder ignores input)
        \item Too high: Over-regularization (blurry reconstructions)
    \end{itemize}
    
    \item \textbf{Implications for Latent Space}:
    \begin{itemize}
        \item Smooth manifold: Regularization ensures continuous, interpolable latent space
        \item Meaningful generation: Sampling $\mathbf{z} \sim \mathcal{N}(0, I)$ produces realistic images
        \item Class separation: While regularized, latent space can still learn discriminative features
        \item Dimensionality: Optimal latent dimension balances capacity vs. regularization
    \end{itemize}
\end{itemize}

\paragraph{Balance Between Terms:}
\begin{itemize}
    \item High reconstruction loss $\rightarrow$ Poor image quality
    \item High KL loss $\rightarrow$ Over-regularization, blurry reconstructions
    \item Optimal balance is achieved through training
\end{itemize}

\subsection{Latent Space Interpolation}

\subsubsection{Objective}
Explore latent space structure through interpolation between class means.

\subsubsection{Method}
\begin{enumerate}
    \item Compute mean latent vectors for "smile" and "non-smile" classes:
    \begin{align}
    \mu_{\text{smile}} &= \frac{1}{|\mathcal{S}|} \sum_{\mathbf{x} \in \mathcal{S}} \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}[\mathbf{z}] \\
    \mu_{\text{non-smile}} &= \frac{1}{|\mathcal{N}|} \sum_{\mathbf{x} \in \mathcal{N}} \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}[\mathbf{z}]
    \end{align}
    \item Define direction vector: $\delta = \mu_{\text{smile}} - \mu_{\text{non-smile}}$
    \item Perform interpolation with $\alpha \in [-3, 3]$:
    \begin{equation}
    \mathbf{z}_{\text{interpolated}} = \mathbf{z}_{\text{sample}} + \alpha \times \delta
    \end{equation}
    \item Decode interpolated vectors to generate images
\end{enumerate}

\textbf{Observations:}
\begin{itemize}
    \item \textbf{Smooth Transition}: Gradual morphological changes observed across interpolation steps

    \item \textbf{Feature Disentanglement}: The interpolation demonstrates that smile attribute is encoded in a semantically meaningful direction
    \item \textbf{Continuous Manifold}: Smooth transitions validate the latent space forms a continuous, well-structured manifold
\end{itemize}

    \item \textbf{Proper regularization}: KL divergence ensures structure compatible with standard normal prior
\end{itemize}

\subsection{Limitations}

\begin{enumerate}
    \item \textbf{Resolution constraints}: Fixed 128×128 resolution limits fine detail preservation
    \item \textbf{Latent dimension}: 32 dimensions may be insufficient for highly complex variations
    \item \textbf{Class separation}: While classes are separated, perfect disentanglement is challenging
    \item \textbf{Computational cost}: Training requires significant GPU resources
\end{enumerate}

\section{Conclusions}

This project successfully implements and evaluates a Variational Autoencoder for facial image generation and reconstruction. The model demonstrates:

\begin{itemize}
    \item \textbf{Effective compression}: Encoding 128×128×3 images into 32-dimensional latent vectors
    \item \textbf{High-quality reconstruction}: Preserving main features while learning compressed representations
    \item \textbf{Generative capability}: Producing diverse and realistic images from latent samples
    \item \textbf{Interpretable latent space}: Enabling semantic manipulation through interpolation
\end{itemize}

The results validate the effectiveness of VAEs for unsupervised representation learning and provide a foundation for exploring more advanced generative modeling techniques.
